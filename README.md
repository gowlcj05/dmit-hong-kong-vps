## 香港 VPS 的价格差，八成差在线路上

港区 VPS 的价格带拉得很开，从每月十几块人民币的入门机，到每月几百美元的旗舰款都有。差距不在 CPU 也不在硬盘，主要在回程路由。

常见的三档：

**国际线路（纯 BGP / Tier 1）**：接入 RETN、NTT、GSL 这类国际骨干，做欧美和东南亚互联很舒服，香港到欧洲的延迟甚至比部分美西节点还低。但它对中国大陆不做任何优化，电信联通用户买回去可能发现延迟比美国机器还高。价格最低，带宽和流量给得最大方。

**半优化（CMI / 9929 这类）**：回程走中国移动国际或联通精品线路，移动用户体验明显好于电信联通。属于「钱不够但还是要照顾国内访问」的折中方案。

**全优化（CN2 GIA）**：电信去回程都走 CN2 GIA，联通走 AS4837 + AS10099，移动走 CMI 直连。三网都比较稳，晚高峰丢包少，价格也最贵。DMIT 的香港 Premium 就是这一档。

判断标准很朴素：你的用户主要在国内，就得买优化线路；你的业务面向海外，国际线路反而更划算，多花的钱是浪费。
